## English

### The Core Principle

**You cannot build a community. You can only create the conditions for one to form.** Every community failure traces back to one of two mistakes: starting too early (pre-PMF), or treating community as a distribution channel instead of a mutual-value ecosystem. This playbook is organized around that flywheel: great product → organic love → self-generated content → community formation → ambassador enablement → more users → repeat.

### What's Inside

- **Phase 0 readiness check** — pre-PMF gates; when community kills instead of grows
- **Ambassador program architecture** — tier design, points systems, onboarding, retention
- **Community-led growth (CLG) flywheel** — how Lovable reached $50M ARR in 6 months with zero outbound sales
- **Platform playbooks** — Discord, Slack, Lark setup; channel structure, moderation, bots
- **Event operations** — AMAs, hackathons, online/offline meetups; runbooks & templates
- **Health metrics dashboard** — DAU/MAU ratio, retention cohorts, ambassador activity KPIs
- **UGC & KOC strategy** — turning active members into creators and micro-influencers
- **Build-in-public framework** — roadmap sharing, changelogs, community-as-feedback-loop
- **Case studies** — Notion (waitlist → enterprise), Lovable (CLG), AFFiNE (0→60K stars), ClickUp, Asana, Lark

## 中文

### 核心原则

**社区不是「建」出来的，你只能创造让它自发形成的条件。**社区运营的失败几乎都源于两个错误：启动太早（PMF 之前），或者把社区当成分发渠道而不是价值互换的生态。这份手册围绕社区飞轮展开：好产品 → 自发喜爱 → 用户自产内容 → 社区成形 → 大使赋能 → 更多用户 → 循环。

### 内容清单

- **Phase 0 就绪检查**——PMF 前的准入门槛；什么情况下做社区反而害了产品
- **大使计划架构**——分层设计、积分体系、onboarding、留存
- **社区驱动增长（CLG）飞轮**——Lovable 如何靠零外呼销售 6 个月做到 $50M ARR
- **平台实操**——Discord / Slack / 飞书搭建、频道结构、管理与 bot
- **活动运营**——AMA、黑客松、线上线下 meetup 的完整 runbook 与模板
- **健康度指标看板**——DAU/MAU、留存 cohort、大使活跃 KPI
- **UGC 与 KOC 策略**、**Build in Public 框架**
- **案例库**——Notion、Lovable、AFFiNE（0→60K stars）、ClickUp、Asana、Lark
