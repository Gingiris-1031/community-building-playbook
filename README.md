## What's Inside

- **Phase 0 Readiness Check** — Pre-PMF gates; when community kills instead of grows
- **Ambassador Program Architecture** — Tier design, points systems, onboarding, retention
- **Community-Led Growth (CLG) Flywheel** — How Lovable reached $50M ARR with zero sales in 6 months
- **Platform Playbooks** — Discord, Slack, Lark setup; channel structure, moderation, bots
- **Event Operations** — AMAs, hackathons, online/offline meetouts; runbooks & templates
- **Health Metrics Dashboard** — DAU/MAU ratio, retention cohorts, ambassador activity KPIs
- **UGC & KOC Strategy** — Turning active members into content creators and micro-influencers
- **Build-in-Public Framework** — Roadmap sharing, changelogs, community-as-product-feedback
- **Case Studies** — Notion (waitlist→enterprise), Lovable (CLG $50M ARR), AFFiNE (0→60K GitHub stars), ClickUp, Asana, Lark

## Based On

Real-world community operations from:
- **AFFiNE** — 0→60K GitHub stars, 14 countries, 34 community ambassadors (built by Iris Wei @WeiYipei)
- **Lovable** — $0→$50M ARR in 6 months, community-led growth with zero outbound sales
- **Notion** — Ambassador program scaling from internal beta to 30M+ users
- **ClickUp / Asana / Lark** — Enterprise community operations at scale
